# GayOS

Experimental Arch Linux-based Live ISO with Hyprland Wayland compositor.

## Features

- Arch Linux base
- Hyprland + greetd auto-login
- Kitty terminal with custom ASCII logo
- NetworkManager, PipeWire
- Custom boot branding

## Build

```bash
sudo pacman -S archiso
sudo mkarchiso -v -w ../work -o ../out .
```
